# Part C Exploration Notes

Part C is separate from the Chicago inspection workflow. Use the checklist to plan your own experiments and write the four sections in your own words. These notes do not record completed experiments.

| Topic | Evidence to produce |
| --- | --- |
| C1 Feed queries | Build a SQLite feed query over follows and posts, then compare its results, query plans, and timings before and after an index on author and creation time. Explain when you would retrieve a feed on read or precompute it on write. |
| C2 Pull requests and CI | Set up a pull-request workflow that runs lint and the test suite. Add a PR template and review checklist and explain what should block a merge. |
| C3 System design theory | Define ten terms with an example for each. Pick one trade-off and explain which requirement would change your decision. |
| C4 Design workflow | Write a one-page design for a small system. Start with the requirements and assumptions, estimate usage, sketch the components and data flow, and describe how you would review the design. |
